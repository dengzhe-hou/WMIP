# Resource icons

The Hugging Face logo is the official full-color SVG from the [Hugging Face brand assets](https://huggingface.co/brand), downloaded from [hf-logo.svg](https://huggingface.co/datasets/huggingface/brand-assets/resolve/main/hf-logo.svg). Its artwork and colors are unchanged; the icon and badge only scale it to fit.

The globe, code, book and tag icons and the resource badge layouts were drawn for this repository. Icons use a 24 × 24 view box. Badges embed their icons and use no external image or font dependencies.
